### Rodando a ferramenta de gerenciamento do blog

> https://github.com/valterbarros/blogging
> Atualmente a ferramenta de CLI está sendo usada nesse repo como [git submodule](https://www.atlassian.com/git/tutorials/git-submodule)

#### Instruções de uso

Comando geral

```bash
./blogging/cli --help

```

Sub comandos de posts

```bash
./blogging/cli posts --help
```

Executar o **editor+preview** para edição de posts

```bash
./blogging/cli posts edit

# abra o link no navegador http://localhost:12769
```
